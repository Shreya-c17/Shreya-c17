## 🧭 [Adaptive Activity Discovery ↗](https://github.com/Shreya-c17/Adaptive-Activity-Discovery)

**A product case study exploring how activity discovery can become more relevant as user context becomes clearer.**

### Product Focus

Designed an adaptive discovery experience that responds to increasing levels of user intent and context rather than treating every user as having the same needs.

### Product Work

- Problem framing and opportunity definition
- User and stakeholder analysis
- Confidence-aware product design
- Adaptive discovery and ranking logic
- Product specification and requirements
- Product decision-making and tradeoffs
- Success metrics and experimentation
- Interactive product prototyping

### Core Product Idea

`User Signals → Context Confidence → Adaptive Discovery → Relevant Activities → Availability Decision`

The experience becomes more specific only as stronger evidence about user intent becomes available.

**[Interactive Prototype](https://onarrival-activities.vercel.app/) · [GitHub Repository](https://github.com/Shreya-c17/Adaptive-Activity-Discovery)**
